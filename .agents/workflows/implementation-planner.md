## Istruzioni operative:
1. Leggi la skill `.agents/skills/implementation-planner/SKILL.md`.
2. Ispeziona `docs/guidelines-index.md` e leggi tutte le linee guida pertinenti al dominio.
3. Esplora il codice sorgente per comprendere a fondo il contesto.
4. Formula un piano di implementazione dettagliato (Obiettivo, File da modificare, Verification Plan).
5. **FERMATI**: presenta il piano all'utente e attendi la sua approvazione esplicita prima di modificare qualsiasi file di codice.
